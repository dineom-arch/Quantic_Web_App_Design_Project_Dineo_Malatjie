# Café Fausse Frontend

This is a Vite + React frontend for the Café Fausse Restaurant Platform.

Setup (Windows PowerShell):

```powershell
cd "03 Frontend Code/frontend"
npm install
npm run dev
```

The app expects the backend API to be available at `http://localhost:5000/api` by default. To change, set `VITE_API_BASE` in your environment.
